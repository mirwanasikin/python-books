# Appendix A — Python Keywords Reference

Python has 35 "hard" keywords that cannot be used as identifiers.

| Keyword | Week | Summary |
|---------|------|---------|
| `False` | 1 | Boolean false |
| `None` | 1 | Singleton null object |
| `True` | 1 | Boolean true |
| `and` | 1 | Boolean AND |
| `as` | 1/3 | Alias for imports / with / except |
| `assert` | 2/3 | Debugging check |
| `async` | 4 | Mark function as coroutine |
| `await` | 4 | Wait for coroutine |
| `break` | 1 | Exit loop |
| `class` | 4 | Define a class |
| `continue` | 1 | Skip to next loop iteration |
| `def` | 2 | Define a function |
| `del` | 2 | Delete a reference |
| `elif` | 1 | Else-if conditional |
| `else` | 1 | Else conditional / loop else |
| `except` | 2 | Catch exception |
| `finally` | 2 | Cleanup after try/except |
| `for` | 1 | Iteration loop |
| `from` | 1/2 | Selective import |
| `global` | 2 | Declare global scope |
| `if` | 1 | Conditional |
| `import` | 1/2 | Import module |
| `in` | 1 | Membership test |
| `is` | 1 | Identity test |
| `lambda` | 2 | Anonymous function |
| `nonlocal` | 2 | Declare outer (non-global) scope |
| `not` | 1 | Boolean NOT |
| `or` | 1 | Boolean OR |
| `pass` | 1 | Null statement (no-op) |
| `raise` | 2 | Trigger exception |
| `return` | 2 | Exit function with value |
| `try` | 2 | Start exception block |
| `while` | 1 | Condition-based loop |
| `with` | 2 | Context manager block |
| `yield` | 4 | Generator value return |

**Soft Keywords:** `match`, `case`, `_`, `type` (introduced in 3.10+).
